# ManuART

Catálogo digital de ManuART — artesanía (collares, brazaletes, pendientes), body painting y tatuaje, hecho por un artesano mexicano itinerante.

Sitio estático de una sola página (HTML/CSS/JS, sin dependencias) con animaciones de scroll.

## Desarrollo

Abre `index.html` directamente en el navegador, no requiere build ni instalación.
